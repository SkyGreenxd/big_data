# WebHDFS CLI на Go

[Теория и подготовка к защите](../../docs/pr1-theory.md).

## Сборка, запуск и проверка

Из корня проекта:

```bash
make pr1
```

`make pr1` собирает CLI первой работы, запускает HDFS, ожидает готовности
NameNode и DataNode и открывает клиент от пользователя `root`. После `exit`
контейнеры продолжают работать.

Запуск CLI при уже работающем HDFS:

```bash
go run ./cmd/pr1 localhost 9870 root
```

Остановка с удалением данных HDFS:

```bash
docker compose -f internal/pr1/docker-compose.yaml down -v
```

Внутри CLI команда `lmkdir <dir>` создаёт папку в текущем локальном каталоге.
Команда `lappend <source-file> <target-file>` дописывает содержимое одного
локального файла в конец другого. Оба файла должны уже существовать.

Compose-конфигурации первой и второй работ используют одинаковые порты HDFS;
запускайте их по очереди.
